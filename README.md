# Viaje en moto · 2026

Plan de viaje del **25 de noviembre al 11 de diciembre de 2026**, por Chile y Argentina.

**Sitio:** https://jartazaf.github.io/travesia-lagos-2026/

## Información disponible

- **Recorrido:** 17 jornadas en un selector de días, con ficha individual, kilómetros estimados, visitas, advertencias, navegación entre jornadas y enlaces a Google Maps. La banda superior permite saltar a etapas principales.
- **Alojamientos:** 8 bases, fechas y reservas. La barra de 16 noches permite acceder directamente a cada alojamiento; las tarjetas despliegan el detalle.
- **Clima:** pronóstico por base y fecha de estadía con temperatura mínima/máxima, probabilidad máxima de lluvia, viento máximo y ráfagas. Muestra «Sin pronóstico todavía» cuando las fechas están fuera de los 16 días disponibles.
- Interfaz responsive para móvil y computador, sin mapa embebido ni bitácora. Se preservan las rutas viales y las advertencias de ripio.

## Actualizar información

- Editar `route-data.js` para cambiar fechas, noches, destinos, visitas, distancias y estado de las reservas.
- `index.html` contiene el diseño y comportamiento de la página.
- Los cambios subidos a `main` se publican mediante GitHub Pages.
- `weather.js` contiene coordenadas aproximadas de las bases y consulta Open-Meteo **solo al abrir la pestaña Clima**. Si cambias una localidad de alojamiento, actualiza también sus coordenadas en ese archivo.
- El pronóstico se consulta desde el navegador; no se guardan datos meteorológicos en el repositorio ni se afirma disponibilidad más allá de 16 días.
- Fuente: [Open-Meteo](https://open-meteo.com/en/docs), licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), para uso personal no comercial.
